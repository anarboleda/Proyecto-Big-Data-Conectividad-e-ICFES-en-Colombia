# Segunda Entrega - Proyecto de Investigación Big Data
## Conectividad a Internet y Resultados ICFES en Municipios de Colombia

## Contenido de esta Entrega

Esta segunda entrega profundiza en los hallazgos de la primera entrega mediante análisis avanzados, modelado predictivo y formulación de recomendaciones de política pública.

| Archivo | Tipo | Descripción |
|---|---|---
| `Analisis_Predictivo.ipynb` | Notebook |  Modelos de predicción y machine learning avanzado |
| `Analisis_Causal.ipynb` | Notebook |  Análisis de causalidad y factores influyentes |
| `Recomendaciones_Politica.ipynb` | Notebook | Propuestas basadas en datos para decisiones públicas |
| `Documento-entrega2.pdf` | Documento |  Informe formal y conclusiones finales |
| `Presentación_Final.pdf` | Documento |  Presentación ejecutiva de resultados |

---

##  Objetivos de la Segunda Entrega

### Análisis Avanzado
- ✓ Profundizar en las relaciones identificadas en la primera entrega
- ✓ Desarrollar modelos predictivos de desempeño ICFES
- ✓ Análisis de causalidad entre variables
- ✓ Identificación de factores de mayor influencia

### Recomendaciones
- ✓ Formular propuestas de política pública basadas en datos
- ✓ Priorizar municipios para intervención territorial
- ✓ Sugerir acciones para mejorar conectividad e ICFES
- ✓ Desarrollar estrategias de implementación

### Documentación
- ✓ Informe técnico completo y final
- ✓ Presentación ejecutiva sintetizada
- ✓ Documentación de metodologías avanzadas

---

### Recomendaciones de Política
- **Priorización territorial:** Municipios que requieren intervención urgente
- **Acciones estratégicas:** Iniciativas específicas por contexto municipal
- **Indicadores de seguimiento:** Métricas para evaluar progreso
- **Financiamiento:** Estimaciones de inversión requerida

---

## Metodología

### Técnicas de Machine Learning
- Regresión lineal y no-lineal
- Árboles de decisión y Random Forest
- Redes neuronales (si aplica)
- Validación cruzada y tuning de hiperparámetros

### Análisis Estadístico Avanzado
- Tests de hipótesis multivariados
- ANOVA factorial
- Análisis de mediación
- Modelos mixtos con efectos aleatorios

### Visualización
- Gráficos predictivos
- Matrices de importancia de variables
- Mapas de impacto por municipio
- Dashboards interactivos

---

- Los análisis se basan en datos validados de la Primera Entrega
- Se utiliza PySpark para procesamiento escalable
- Todos los modelos se validan con múltiples técnicas
- Se prioriza la reproducibilidad y la transparencia metodológica
- Los resultados están sujetos a sensibilidad y análisis de robustez
