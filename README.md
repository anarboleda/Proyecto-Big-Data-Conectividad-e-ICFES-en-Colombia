# Análisis Big Data: Conectividad a Internet y Resultados ICFES en Municipios de Colombia

![Logo Javeriana](Javeriana.svg)

---

## Descripción del Proyecto

Este proyecto investigativo analiza la relación entre la **conectividad a internet** y los **resultados en pruebas ICFES** en municipios colombianos. Utilizando técnicas de análisis de datos y machine learning, se busca identificar correlaciones, patrones y factores que influyen en el desempeño educativo.

### Objetivos Principales
- Analizar la calidad de conectividad en municipios colombianos
- Evaluar el impacto de la conectividad en resultados ICFES
- Identificar factores climáticos y socioeconómicos relacionados
- Generar recomendaciones de política pública
